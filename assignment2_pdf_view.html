IMPROVEMENTS MADE

The static HTML resume has been transformed into a modern, responsive personal resume website inspired by the InBio template design language for PC and mobile displays (100% Pure HTML5 & CSS3):

  • Neumorphic & Soft Elevation Card Aesthetics: Crafted layered dual-directional drop shadows (var(--shadow-neumorph)) and inset shadows for metrics, portrait cards, and highlight sections.
  • Integrated High-Resolution Student Portrait: Styled and embedded student portrait across the Hero showcase card, sticky navbar brand, Profile section frame, and contact cards.
  • Pure CSS Sticky Navigation with Checkbox Drawer: Implemented position: sticky; top: 0; with backdrop blur and pure CSS :checked hamburger toggle for mobile devices.
  • Consistent Modern Color Palette: Structured CSS variables (:root) featuring a light neutral background (#ecf0f3), deep slate headers (#1e2125), and vibrant coral red accent (#ff014f).
  • Clean Montserrat Typography: Applied structured font weights (400, 600, 700, 800) with refined letter-spacing for section titles and subtitles.
  • CSS Grid Layouts for Key Strengths ("What I Do"): Designed a 3-column card grid with numeric indicators, descriptions, and interactive hover arrow animations (↗).
  • CSS-Based Vertical Education Timeline: Implemented a vertical timeline with connecting gradient tracks, pulsating node markers, and institution cards.
  • Class, ID, and Element Selectors: Organized code cleanly with HTML5 semantic elements, modular component classes (.inbio-card, .chip-item, .btn-inbio-primary), and section ID targets.
  • Interactive Micro-Animations & Hover Effects: Smooth card elevation on hover (transform: translateY(-7px)) and interactive button transitions.
  • PC & Mobile Responsive Adaptability: Complete responsiveness across 1440px desktop, 1024px tablet, and 768px/480px mobile viewports without horizontal scroll.
